# QA: как тестировать Krug

## Где тестировать

- **Preview на каждый PR** (появится на шаге 0.3, после подключения хостинга): ссылка будет в PR.
- **Локально** (нужны Node 22+ и pnpm): см. «Run locally» в корневом README. API — http://localhost:8787,
  документация API — http://localhost:8787/docs, приложение — http://localhost:8081.

## Тестовые пользователи (временно, до шага 0.7)

Входа пока нет. Внизу главной и страницы приглашения есть блок «Тестовый пользователь»: anna, arman, mariam,
davit. Переключение = «я теперь другой человек». В продакшене этого блока не будет (CI-проверка добавится на
шаге 0.7). Чтобы тестировать двух людей одновременно — два окна браузера (обычное + инкогнито).

## Чек-лист v0 (круг и приглашения)

Проверять: телефон (ширина ~390px) и десктоп; светлая и тёмная тема; hy / ru / en.

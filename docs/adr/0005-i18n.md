# 0005 — Three languages from day one, typed

**Status:** accepted · 2026-11-10

**Decision.** `packages/i18n` holds Armenian, Russian and English messages. English is the reference shape; the
other two must have exactly the same keys (compile-time check). The app uses i18next with typed keys. The
language is the saved choice, else the device language, else Armenian. Search uses `searchKey()` so "Երևան",
"Yerevan" and "Erevan" match. Dates are formatted with `Intl` in the circle's own time zone.

**Consequences.** Adding a string means adding it in three languages in the same PR. Armenian drafts are reviewed
by a native speaker before launch.
